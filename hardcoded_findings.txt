[FINDING-01]
File: spike/swarm-tunnel/src/main.rs:168-177
Category: Cryptographic Weakness / Key Derivation
Severity: CRITICAL
Code Snippet:
```rust
fn pair_code_key(code: &str) -> SecretKey {
    let normalized = normalize_pair_code(code);
    let mut hasher = Sha256::new();
    hasher.update(b"swarm-pair-v1:");
    hasher.update(normalized.as_bytes());
    let digest = hasher.finalize();
    let mut bytes = [0u8; 32];
    bytes.copy_from_slice(&digest);
    SecretKey::from_bytes(&bytes)
}
```
Danger & Impact:
The 32-byte Iroh QUIC tunnel private key is directly derived from a 6-digit numeric pairing PIN with a single round of SHA-256 and a hardcoded static salt (`b"swarm-pair-v1:"`). A 6-digit PIN has only 1,000,000 possible states. An attacker can precompute the entire keyspace on a standard GPU in less than 1 second. Because the derived EndpointId is announced to public Pkarr/DHT servers, any passive eavesdropper can look up the ID, immediately recover the private key, impersonate either the host or phone, decrypt all tunnel traffic, intercept inference tensors, and execute unauthorized GGML RPC commands.
Recommendation:
Do not derive asymmetric identity keys directly from a low-entropy PIN without an interactive authenticated key exchange (e.g., SPAKE2, OPAQUE, or SPAKE2+ over TLS/Noise) or require high-entropy pairing tokens.

[FINDING-04]
File: coordinator_http.cpp:127-139
Category: Security / DNS Rebinding & Substring Match Bypass
Severity: CRITICAL
Code Snippet:
```cpp
if (req.has_header("Host")) {
    std::string host = req.get_header_value("Host");
    if (host.find("127.0.0.1") == std::string::npos &&
        host.find("localhost") == std::string::npos &&
```
