Architectural Leak in UI

The Single-Client RPC Probe Lockout Trap

Code Evidence: In DevicesPanel.tsx:170 & 208, health probes are hardcoded to skip testing and fabricate mock data during active inference:
if (isCoordinatorActive) { /* do not open TCP socket - steals single-client connection! */ }

The Safe UX Solution: Coordinator-Brokered Telemetry

Never let the frontend probe the raw RPC port directly. The C++ Coordinator already records live RTT and bytes transferred for each token chunk. Surface this passive telemetry directly to the Device Card without issuing out-of-band TCP handshakes.
